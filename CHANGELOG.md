# История изменений

## ЛР1 — 2026-10-20

- Подготовлены отчёт, паспорт проекта, карта функций, риски и план семестра.
- Добавлены структура документации, ссылки `src`/`tests`, пример окружения и HTTP smoke-проверка.
- Исправлены передача настроек в Compose и исключение локальных секретов из образа.
- Основной запуск использует локальное хранилище; MinIO вынесен в профиль `s3` из-за недоступности образов.
- Зафиксированы версии Python, Node.js и Nginx; сборка npm использует `npm ci`.
- Настроен ESLint для TypeScript, исправлены замечания и проверки CI.
- Убрана декларация MIT для собственного frontend по решению автора; лицензии зависимостей сохранены.
- Созданы GitHub issues для согласования и дальнейших инженерных работ.

Исходное состояние: коммит `7ac2104a`. История до ЛР1 доступна в Git.
