# Исходный код

`backend` ссылается на `../backend/app`, `frontend` — на `../frontend/src`.
Ссылки сохраняют структуру существующего проекта без копирования исходников.
Docker и CI используют оригинальные пути. На Windows для checkout символических ссылок может понадобиться режим разработчика; оригинальные каталоги доступны независимо от ссылок.
